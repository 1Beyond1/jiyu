# 项目管理

更新：2026-10-24。项目名称：集屿 / Jiyu（用户已确认）。

## 用户目标

把微信等渠道零散收到的文件，转为一个链接集中收集，按任务与提交人整理。部署到自己的 VPS；存储可选择本地或网盘；通过批量工具和悬浮 AI 减少重复劳动。

用户已确认简约高级、参考 Claude 的暖纸色、炭灰文字、陶土点缀与衬线标题。当前按「继续直至第一版可用」推进本地存储 MVP，前端接入真实服务；原型浏览器记录与正式数据隔离。

## 控制目录增长

1. 不创建 `v2/`、`final/`、`backup/` 等源码副本。历史依靠 Git，当前界面作为首个版本纳入管理；推送按用户授权执行。
2. 不提前搭空的 monorepo。真正开始后端时再增加 `server/`，复用 TypeScript 类型，先保持单仓库。
3. `node_modules/`、`dist/`、`.cache/`、`.artifacts/` 是可再生内容。截图与临时样本仅进 `.artifacts/`；npm 缓存可随时清理。
4. 开发依赖仅在本地/构建阶段使用。部署只打包应用构建结果与正式服务依赖，不把 npm 缓存和原型截图带上 VPS。
