# 第一版界面方向

## 主题

集屿是文件收集工作台。主要用户是经常通过微信等方式收资料的个人/小团队管理者。首页的首要任务是看清哪些收集正在进行、收到什么，以及接下来该整理什么。

用户偏好：**简约高级**。已应用 frontend-design 技能。

## 设计变量

- 画布：雾白 `#F7F9F8`。
- 面板：纸白 `#FFFFFF`。
- 文字：深林灰 `#29392F`。
- 操作色：森林绿 `#356A54`。
- 边框：浅灰绿 `#E8ECE9`。
- 小面积分类辅助色：灰蓝、沙色；不参与主操作层级。

字体：英文数字使用 DM Sans，中文优先 Noto Sans SC，回退系统中文字体。只使用 Google Fonts 的可选 CSS 字体请求；字体失败时界面仍可运行。正式 VPS 版建议打包字体子集或移除远程字体请求。

## 布局与识别点

左侧稳定导航，中间单列工作流。首页从轻量概览，进入收集卡片，再到真实文件样式的表格，最后引导整理。视觉识别点是三种文件收集卡片的柔和分类颜色与细进度条；其他区域保持安静，不叠加装饰性图表。

不采用“巨大数据卡片 + 装饰渐变”作为首页主体，因为本项目的核心是收齐文件和快速定位。统计行尽量轻，文件操作保留明确的表格结构。

## 交互约定

- 任务标题进入该任务的文件列表，分享按钮展示链接与提交页预览。
- 表格多选后出现批量操作条。命名先预览，检查扩展名与重名后才应用。
- AI 是右下角悬浮入口，点击打开侧浮层；操作继续进入同一套命名预览。
- 网盘未接入时显示真实状态，不显示虚假的“已连接”或“安全备份完成”。
- 提交页独立于管理工作台；格式、容量和提交结果清楚显示。
- 桌面三列任务卡片，中等宽度两列，手机单列；表格在自己的容器内横向滚动，不撑宽页面。
- 原生 dialog 负责模态焦点和 Escape 退出；可见 focus 样式；尊重系统减少动态效果设置。

## 下一轮反馈重点

先确认整体气质、绿色使用程度、信息密度、任务卡片与文件表格是否顺手。之后按真实收集场景调整字段，避免在视觉未确认前堆后端功能。
